## 📝 Sobre o Projeto

O **Indaia Fighter** nasceu como um desafio acadêmico para a disciplina de *Projeto Integrado de Jogos Digitais*. A ideia central, idealizada pela equipe, é unir a mecânica clássica e frenética dos jogos de luta arcade (estilo *Street Fighter II*) com a rica identidade cultural de **Indaiatuba - SP**.

O jogo substitui os cenários genéricos por locais icônicos da nossa cidade, trazendo figuras inspiradas na vida real para o ringue digital. É um tributo à nostalgia dos anos 90, totalmente temperado com a cultura local!

---

## 🎮 Como Jogar

O jogo possui suporte nativo para **Multiplayer Local (PvP)**, permitindo que dois jogadores dividam o mesmo teclado ou utilizem joysticks.

### Controles Padrão (Teclado)
| Ação | Player 1 | Player 2 |
| :--- | :---: | :---: |
| **Movimentação** | `W` `A` `S` `D` | `Setas` |
| **Pular** | `Espaço` | `Seta Cima` |
| **Abaixar** | `S` | `Seta Baixo` |
| **Soco** | `F` | `K` (ou NumPad 1) |
| **Chute** | `G` | `L` (ou NumPad 2) |
| **Bloqueio** | `Shift Esquerdo` | `Shift Direito` |

### Controles (Joystick / Controle)
| Ação | Botão (Layout PlayStation) |
| :--- | :--- |
| **Movimentação (Andar)** | `D-Pad` (Setas) / `Analógico` |
| **Abaixar** | `Para baixo` (D-Pad / Analógico) |
| **Pular** | `X` |
| **Soco** | `Quadrado` |
| **Chute** | `Círculo` |
| **Bloqueio** | `L1` |
| **Pausar / Retomar Jogo** | `Options` |

> **Dica de Combate:** Se o seu personagem estiver abaixado, ele conseguirá esquivar de socos e chutes normais do adversário!

## 🏙️ Cenários e Ambientação

O jogo foca na fidelidade visual através da Pixel Art, transformando os principais pontos turísticos de Indaiatuba em verdadeiras arenas de combate:

- 🎭 **Concha Acústica** *(Disponível)*
- 🌳 **Parque Ecológico Barco** *(Disponível)*
- 🛍️ **Polo Shopping** *(Disponível)*
- 💧 **Museu da Água** *(Disponível)*
- 🎓 **Unimax** *(Disponível)*
